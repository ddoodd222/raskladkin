Страница Раскладкина — один файл index.html.

Живой адрес: https://ddoodd222.github.io/raskladkin/
Публикуется сама: после отправки правок на GitHub сайт обновляется за минуту-две.

Кнопки «Скачать» ведут на файл из релиза на GitHub, поэтому DMG рядом с index.html
держать больше не нужно.

Отправить правки страницы на сайт (из папки Raskladkin):
  git add docs && git commit -m "правки страницы" && git push

Новая версия программы:
  ./build.sh && ./make-dmg.sh
  затем выложить dist/Раскладкин-1.0.dmg в новый релиз на GitHub.
