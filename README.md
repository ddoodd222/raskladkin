# Раскладкин

Чинит текст, набранный не в той раскладке (EN ↔ RU). Живёт в menubar.

**[Скачать для macOS](https://github.com/ddoodd222/raskladkin/releases/latest/download/Raskladkin.dmg)** · [о программе](https://ddoodd222.github.io/raskladkin/) · бесплатно, macOS 13+

## Что умеет
- **Хоткей** (по умолчанию ⌘⇧A): чинит выделенный текст, а если ничего не выделено — последнее слово. Решает пословно через словари macOS, смешанный текст не ломает. Повторное нажатие на последнем слове возвращает как было.
- **Автомат**: после трёх подряд слов «не в той раскладке» стирает их и перепечатывает правильно. Порог 2/3/4 настраивается.
- После исправления переключает раскладку под текст (отключается в меню).
- Молчит в терминалах и в полях паролей. Список приложений редактируется в меню.

## Сборка
```bash
./build.sh
```
Скрипт компилирует, собирает `dist/Раскладкин.app`, копирует в `/Applications` и запускает.
После каждой пересборки macOS заново спросит права «Универсальный доступ» — это нормально, подпись без сертификата разработчика меняется при каждой сборке.

## Проверка логики из терминала
```bash
.build/Raskladkin --check ghbdtn hello
.build/Raskladkin --fix "ghbdtn rfr ltkf"
.build/Raskladkin --map
```

## Известная особенность мака
В Command Line Tools остался лишний старый файл `module.modulemap`, из-за которого компилятор падает. `build.sh` обходит это виртуальной подменой. Лечится навсегда одной командой:
```bash
sudo rm /Library/Developer/CommandLineTools/usr/include/swift/module.modulemap
```
